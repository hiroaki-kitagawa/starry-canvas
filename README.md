# Starry Canvas

夜空に散らばる10個の星を探し、1つずつ育ててキャラクターへ成長させるブラウザゲームです。

背景を移動・拡大して星を探し、育成中の星を応援できます。すべての星を育てると、完成記念イラストとお祝いメッセージが表示されます。

## 起動方法

`index.html` をブラウザで開くだけで起動します。

- Webサーバーの起動は不要です
- `npm install`、`npx`、ビルド処理は不要です
- JavaScriptを有効にしてください
- Google Fontsの取得にはインターネット接続を使用しますが、ゲーム本体はローカルファイルで動作します

## 遊び方

1. 星空を移動・拡大して、黄色く輝く星を探します。
2. 星を選択し、星の近くに表示される「育成」ボタンを押します。
3. 育成が始まると、60秒かけて進捗が100%まで増加します。
4. 育成中の星をタップまたはクリックすると応援でき、育成時間が少し短縮されます。
5. 100%になるとキャラクターが完成し、祝福演出とメッセージが表示されます。
6. 10個すべてを完成させると、完成記念イラストと最終メッセージが表示されます。

## 操作方法

### PC

- 星空の移動：マウスドラッグ
- 拡大・縮小：左上の＋・−ボタン、倍率入力、カーソルキー
- 縮小：`←` または `↓`
- 拡大：`→` または `↑`
- 星の選択・応援：クリック
- メッセージを閉じる：×ボタン、背景クリック、`Esc`

マウスで星へカーソルを合わせると、望遠鏡プレビューが表示されます。

### スマートフォン／タブレット

- 星空の移動：1本指スワイプ
- 拡大・縮小：2本指のピンチイン／ピンチアウト、左上の＋・−ボタン
- 星の選択・応援：タップ

スマートフォン横画面では操作方向を次のように使い分けます。

- 横方向の1本指スワイプ：星空を移動
- 縦方向の1本指スワイプ：ページをスクロールし、タイトルや成長ログを表示
- 2本指操作：星空を拡大・縮小

最小倍率で背景全体が表示されている場合、移動できる余地がない方向には星空は動きません。

## 育成ルール

- 星は10個です
- 同時に育成できる星は1個です
- 育成中は他の星を選択できません
- 育成時間は星1個につき60秒です
- 応援1回につき約0.5秒短縮されます
- 1回の育成で短縮できる時間は合計最大5秒です
- 応援には約0.35秒のクールダウンがあります
- 進行状況はリロードするとリセットされます

星の色は進捗に応じて変化します。

| 進捗 | 色 |
|---:|---|
| 0〜24% | 黄色 |
| 25〜49% | 青色 |
| 50〜74% | 赤色 |
| 75〜99% | 紫色 |
| 100% | キャラクター完成 |

## 対応画面

- PC：1024px以上
- タブレット：600〜1023px
- スマートフォン：320〜599px
- スマートフォン横画面：横向きかつ画面高600px以下

背景画像の縦横比を維持し、利用可能な領域内で最大表示します。画面が低い場合やスマートフォン横画面では、ページを縦スクロールできます。

## アセット

| ファイル | 用途 |
|---|---|
| `assets/titlelogo.png` | ゲームタイトルロゴ |
| `assets/background.png` | 星空ワールド背景（2752×1536） |
| `assets/characters/star-01.png`〜`star-10.png` | 完成キャラクター画像 |
| `assets/assemble.png` | 全10星完成時の記念イラスト |

キャラクター画像が読み込めない場合は、開発用プレースホルダーを表示します。

## ファイル構成

```text
starry-canvas/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── config.js
│   ├── utils.js
│   └── main.js
├── assets/
│   ├── titlelogo.png
│   ├── background.png
│   ├── assemble.png
│   └── characters/
│       ├── star-01.png
│       └── ... star-10.png
└── docs/
    └── 仕様書.md
```

JavaScriptはES Modulesを使用せず、`config.js`、`utils.js`、`main.js`の順で通常スクリプトとして読み込みます。これにより、`file://`で`index.html`を直接開いて実行できます。

## 設定の変更

ゲームバランスや表示設定は主に `js/config.js` で変更できます。

- 星の個数と配置
- 育成時間
- 応援による短縮時間
- ズーム上限と変更幅
- 完成メッセージ
- 色変化の閾値
