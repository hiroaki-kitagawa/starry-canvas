# Starry Canvas

夜空に散らばる星を探し、1つずつ育ててキャラクターにするブラウザゲームです。  
背景をドラッグしてマップを移動し、見つけた星をクリックして育成できます。

## 特徴

- `assets/background.png` を使った広大な夜空マップ
- 星をクリックして選択し、「育成」で成長開始
- 進捗に応じて星の色が変化
- 完成時にパーティクルで祝福演出
- 育成中は応援タップで少しだけ成長を早められる
- 成長ログで進行状況を確認できる

## 遊び方

1. 画面をドラッグして、背景の別エリアを表示します。
2. 星をクリックして選択します。
3. 「育成」ボタンを押して成長を開始します。
4. 育成中は星をタップして応援できます。
5. 100% になるとキャラクターが完成し、祝福演出が表示されます。

## 色の変化

- 初期: 黄色
- 25%: 青色
- 50%: 赤色
- 75%: 紫色

## 起動方法

1. `index.html` をブラウザで開きます。
2. そのままプレイできます。ビルドやインストールは不要です。

## キャラクター画像

完成時に表示されるキャラクター画像は `assets/characters/` 配下に配置してください。  
例: `star-01.png` 〜 `star-10.png`
