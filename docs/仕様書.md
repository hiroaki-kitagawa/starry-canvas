## 1. 概要

### 1.1 コンセプト

夜空に散らばる10個の星を探索し、1つずつ育成してキャラクターへ成長させるブラウザ向け育成ゲーム。

### 1.2 プレイ体験

1. 星空を移動・拡大して星を探す
2. 任意の未完成星を選択する
3. 「育成」ボタンで60秒の育成を開始する
4. 応援操作と成長ログを楽しみながら完成を待つ
5. 100%到達時にキャラクターと祝福演出を表示する
6. キャラクターメッセージを確認し、次の星を育てる
7. 10個すべての完成時に記念イラストと最終メッセージを表示する

### 1.3 対象環境

- PCブラウザ
- タブレットブラウザ
- スマートフォンブラウザ（縦向き・横向き）
- 最低想定画面幅：320px

### 1.4 起動方式

- `index.html`を直接開いて起動する
- Webサーバー、パッケージ導入、ビルド処理は不要
- `file://`で動作させるためES Modulesは使用しない
- JavaScriptは次の順で通常スクリプトとして読み込む
  1. `js/config.js`
  2. `js/utils.js`
  3. `js/main.js`

### 1.5 技術構成

| 項目 | 内容 |
|---|---|
| マークアップ | HTML |
| スタイル | CSS |
| ロジック | Vanilla JavaScript |
| ゲームオブジェクト | DOM要素 |
| パーティクル | Canvas 2D API |
| フレーム更新 | `requestAnimationFrame` |
| フレームワーク | なし |
| 永続化 | なし。再読み込みでリセット |

## 3. ゲーム状態

### 3.1 星エンティティ

```js
{
  id: "star-01",
  index: 1,
  x: 0.46,
  y: 0.42,
  progress: 0,
  status: "idle",
  colorPhase: "initial",
  characterImageUrl: "assets/characters/star-01.png",
  loggedMilestones: new Set()
}
```

### 3.2 状態

| 状態 | 意味 |
|---|---|
| `idle` | 未選択・未完成 |
| `selected` | 選択中 |
| `growing` | 育成中 |
| `completed` | 育成完了 |

状態遷移：

```text
idle ──選択──> selected ──育成開始──> growing ──100%──> completed
```

- 同時に選択できる星は1個
- 同時に育成できる星は1個
- 育成中は対象星以外を操作できない
- 完成星は再育成できない
- 完成星の選択ではキャラクターメッセージを表示する

## 4. 星空ステージ

### 4.1 ワールド

| 項目 | 仕様 |
|---|---|
| サイズ | 2752×1536 |
| 背景 | `assets/background.png` |
| 星数 | 10個固定 |
| 星配置 | `STAR_POSITIONS`のプリセット相対座標 |
| 初期カメラ | ワールド中央 |
| 表示枠 | 背景と同じ縦横比で利用可能領域内に最大表示 |

最小倍率では背景全体を表示枠へ収め、余白が生じる軸は中央配置する。カメラはワールド範囲外へ移動できない。

### 4.2 ズーム

| 項目 | 仕様 |
|---|---|
| 実効最小倍率 | 背景全体が表示枠へ収まる倍率。画面サイズから動的計算 |
| 最大倍率 | 150% |
| ボタン変更幅 | 25% |
| 数値入力 | 0.1%単位、実効最小〜150% |
| 基準点 | ボタン・キー操作は画面中央、ピンチは2本指の中点 |

PC操作：

- ＋・−ボタン
- 倍率入力
- `←`／`↓`で縮小
- `→`／`↑`で拡大

タッチ操作：

- 2本指のピンチイン／ピンチアウト
- ＋・−ボタン

### 4.3 パンとページスクロール

| 環境 | 操作 |
|---|---|
| PC | マウスドラッグで星空を移動 |
| スマートフォン縦向き | 1本指スワイプで星空を移動 |
| スマートフォン横向き・高さ600px以下 | 横スワイプで星空移動、縦スワイプでページスクロール |

ドラッグ判定距離は8px。ドラッグ後は星の誤選択を抑止する。最小倍率などでワールドが表示枠に収まっている方向には移動しない。

### 4.4 望遠鏡プレビュー

- `hover: hover`かつ`pointer: fine`のマウス環境のみ有効
- 星へカーソルを合わせると星または完成キャラクターを拡大表示する
- 表示枠の大きさに応じて望遠鏡を縮小する
- タッチ端末では表示しない

## 5. 育成仕様

### 5.1 基本値

| 項目 | 値 |
|---|---:|
| 星の個数 | 10 |
| 星1個の育成時間 | 60,000ms（60秒） |
| 同時育成数 | 1 |
| 育成キャンセル | 不可 |

### 5.2 進捗表示

- プログレスバー
- 整数パーセント
- `残り mm:ss`
- 選択中または育成中の星番号・状態

残り時間は次式で計算する。

```text
残り時間 = 育成時間 × (1 - 進捗 / 100)
```

### 5.3 色フェーズ

| 進捗 | `colorPhase` | 表示色 |
|---:|---|---|
| 0〜24% | `initial` | 黄色 |
| 25〜49% | `blue` | 青色 |
| 50〜74% | `red` | 赤色 |
| 75〜99% | `purple` | 紫色 |
| 100% | `purple`＋`completed` | キャラクター画像 |

### 5.4 応援

| 項目 | 仕様 |
|---|---|
| 操作 | 育成中の対象星をタップ／クリック |
| 1回の短縮 | 500ms |
| 1育成の短縮上限 | 5,000ms |
| クールダウン | 350ms |
| 演出 | 星の脈動と小型パーティクル |
| ログ | 応援メッセージを成長ログへ追加 |

### 5.5 成長ログ

- 育成開始、25%、50%、75%、100%のマイルストーンを表示する
- 応援メッセージを表示する
- 最大4件を保持する
- スマートフォンでは表示高を抑え、領域内スクロールにする

## 6. 完成処理

### 6.1 星1個の完成

1. 進捗を100%にする
2. 状態を`completed`へ変更する
3. 光点をキャラクター画像へ置換する
4. 2.2秒の祝福演出を開始する
5. Canvasパーティクルと中央の「完成！」を表示する
6. 演出中はゲーム操作をロックする
7. 演出後、完成キャラクターへカメラを寄せて150%表示する
8. キャラクターメッセージを画面中央に表示する

### 6.2 キャラクターメッセージ

| 項目 | 仕様 |
|---|---|
| 表示位置 | 画面中央 |
| 内容 | キャラクター画像、星別タイトル、成功メッセージ |
| 自動表示 | 育成完成演出後 |
| 再表示 | 完成キャラクターをクリック／タップ |
| 閉じ方 | ×ボタン、背景、`Esc` |
| 小画面 | カード最大高を画面内に制限し、内部スクロール |

### 6.3 全10星の完成

最後のキャラクターメッセージを閉じた後、全星完成ポップアップを表示する。

| 項目 | 仕様 |
|---|---|
| タイトル | 「おめでとう！」 |
| 画像 | `assets/assemble.png` |
| 本文 | 10個すべての育成完了を祝うメッセージ |
| 表示位置 | 画面中央 |
| 閉じ方 | ×ボタン、背景、`Esc` |
| 小画面 | 画像を縮小し、必要時はカード内部をスクロール |

```text
┌────────────────────────────────────┐
│           titlelogo.png            │
│  背景をドラッグして星を探し、育てよう  │
├────────────────────────────────────┤
│ [キー操作説明]                     │
│ [−][倍率%][＋]                     │
│                                    │
│             星空ステージ             │
│                                    │
├────────────────────────────────────┤
│ 選択状態                            │
│ [進捗バー] 進捗% 残り時間             │
│ 成長ログ                            │
└────────────────────────────────────┘
```

育成ボタンは固定パネル内ではなく、選択した星の近くに表示する。表示枠端ではボタン全体が枠内へ収まるよう位置を制限する。

### 7.1 チュートリアル

- 起動時に4ステップ表示する
  1. 星を探す
  2. 星を選択して育成する
  3. 拡大・縮小する
  4. 完成キャラクターを確認する
- PCでは対象要素付近へ吹き出し表示する
- タッチ端末では画面中央寄りへ表示する
- タッチ端末のズーム説明はピンチと＋・−ボタンを案内する
- 「次へ」「スキップ」「はじめる」を提供する

## 8. レスポンシブ仕様

| 区分 | 条件 | 主な挙動 |
|---|---|---|
| PC | 1024px以上 | 固定ビューポート、キー説明・望遠鏡あり |
| タブレット | 600〜1023px | ロゴ・望遠鏡・余白を縮小 |
| スマートフォン | 320〜599px | 縦積み、ページスクロール、コンパクトUI |
| 横向きスマートフォン | 横向きかつ高さ600px以下 | 横幅優先で星空を拡大、縦スワイプでページ移動 |
| 低いPC／タブレット | 高さ700px以下かつ幅600px以上 | ページスクロールとコンパクト表示 |

共通要件：

- 横方向のページスクロールを発生させない
- 背景の縦横比を維持する
- タップ対象は原則44px以上を確保する
- ポップアップを画面外へ見切れさせない
- 画面回転、`visualViewport`変更、親領域のリサイズに追従する
- Canvas解像度は`devicePixelRatio`を考慮する
- ノッチとホームインジケーターのセーフエリアを考慮する

## 9. アクセシビリティ

- ボタンと入力欄にラベルを設定する
- 進捗をバーだけでなく数値と残り時間でも示す
- ポップアップは`role="dialog"`と`aria-modal="true"`を使用する
- ポップアップ表示時は閉じるボタンへフォーカスする
- ポップアップ表示中は背景スクロールとズームキー操作を停止する
- `Esc`でポップアップを閉じる
- `:focus-visible`でキーボードフォーカスを表示する
- `prefers-reduced-motion: reduce`ではアニメーション時間を最小化する

## 10. 主要設定値

| 定数 | 値 | 用途 |
|---|---:|---|
| `STAR_COUNT` | 10 | 星数 |
| `GROWTH_DURATION_MS` | 60,000 | 育成時間 |
| `CELEBRATE_MS` | 2,200 | 完成演出時間 |
| `CHEER_BOOST_MS` | 500 | 応援1回の短縮量 |
| `CHEER_MAX_TOTAL_MS` | 5,000 | 応援短縮上限 |
| `CHEER_COOLDOWN_MS` | 350 | 応援クールダウン |
| `LOG_MAX_ITEMS` | 4 | ログ最大件数 |
| `WORLD_WIDTH` | 2,752 | ワールド幅 |
| `WORLD_HEIGHT` | 1,536 | ワールド高 |
| `DRAG_THRESHOLD_PX` | 8 | ドラッグ判定距離 |
| `ZOOM_MAX` | 1.5 | 最大倍率 |
| `ZOOM_STEP` | 0.25 | ボタン・キーの倍率変更幅 |

## 12. 受け入れ条件

1. `index.html`を直接開いてゲームが起動する
2. 夜空に10個の星が表示される
3. 星を選択し、育成を開始できる
4. 進捗、残り時間、成長ログが更新される
5. 25%・50%・75%で青・赤・紫へ変化する
6. 育成中の星を応援でき、最大5秒短縮される
7. 100%でキャラクター、パーティクル、「完成！」を表示する
8. 完成メッセージが画面中央に収まる
9. 全10星完成時に`assemble.png`と最終メッセージを表示する
10. PCでドラッグ、キー、ボタン、倍率入力が動作する
11. タッチ端末で1本指移動と2本指ピンチが動作する
12. 横向きスマートフォンで横スワイプによる星空移動と縦スワイプによるページ移動が動作する
13. 320px幅から横スクロールや主要UIの重なりが発生しない
14. 画面回転後も星、背景、ボタン、パーティクルの座標が一致する
