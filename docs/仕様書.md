## 1. 概要

### 1.1 コンセプト

夜空に輝く小さな星を選び、育成することで、かわいい人間型／マスコットキャラクターへと成長させるブラウザ向け育成ゲーム。

### 1.2 プレイ体験の流れ（要約）

1. 夜空に約10個の星が表示される
2. プレイヤーが任意の星を選択する
3. 「育成」ボタンを押すと、その星の育成が始まる
4. 進捗に応じて星の光の色が変化する
5. 100%到達でキャラクターが完成し、祝福演出が表示される
6. 演出後、未完成の別の星を選択できるようになる

### 1.3 対象プラットフォーム

- Web ブラウザ（デスクトップ優先、モバイルでも操作可能）

### 1.4 技術スタック（確定）

| 項目 | 内容 |
|------|------|
| 構成 | **HTML / CSS / JavaScript** のシンプルな構成（ビルドツール・フレームワークなし） |
| エントリ | `index.html` をブラウザで開いてプレイ |
| スタイル | `css/style.css`（案） |
| ロジック | `js/main.js`（案。必要に応じて分割可） |
| 描画 | DOM 要素で夜空・星・UI を構成（Canvas API は必須としない） |
| アセット | `assets/characters/` にキャラクター画像を配置 |

推奨ディレクトリ構成：

```

├── assets/
│   └── characters/
│       ├── star-01.png
│       └── ...
└── docs/
    └── 仕様書.md
```

## 2. 用語定義

| 用語 | 意味 |
|------|------|
| 星（Star） | 夜空上の光点。育成対象のエンティティ |
| 育成 | 選択中の星の進捗を時間経過で進める行為 |
| 進捗（Progress） | 0〜100% の育成度 |
| 段階色 | 進捗閾値に応じて切り替わる星の発光色 |
| 完成キャラクター | 進捗 100% 到達後に表示されるキャラクター画像 |
| 祝福演出 | 完成時に再生されるお祝い演出 |
| 選択中の星 | UI 上でハイライトされ、育成操作の対象となっている星 |

## 3. ゲームオブジェクト

### 3.1 夜空（ステージ）

| 項目 | 仕様 |
|------|------|
| 背景 | `assets/background.png` を広大なワールド背景として使用 |
| ワールドサイズ | 画像実寸（2752×1536） |
| 表示領域 | 画面の主領域を占めるビューポート（プレイ画面） |
| 初期視点 | 背景の中央がプレイ画面の中央に来るようカメラを配置 |
| 移動 | 背景をドラッグしてパンし、別エリアをプレイ画面に表示する |
| 星の配置 | 育成星はワールド全体に散りばめ、探索しながら見つける |
| インタラクション | 星のクリック選択が可能。ドラッグ中は選択しない |

### 3.2 星

| 項目 | 仕様 |
|------|------|
| 初期個数 | **10個**（固定。将来的に可変可） |
| 初期見た目 | 小さな光点（**黄色**の点光源）。大きさは画面幅に対して十分小さい |
| 配置 | 夜空内に重複しすぎないようランダムまたはプリセット座標で配置 |
| 状態 | `未選択` / `選択中` / `育成中` / `完成` |
| 完成後 | 光点の代わりに、対応するキャラクター画像を表示する |
| 再育成 | 完成済みの星は育成対象外（クリックしても育成不可） |

#### 3.2.1 星の状態遷移

```
[未選択]
   │ クリック
   ▼
[選択中] ──育成ボタン──► [育成中] ──進捗100%──► [完成]
   ▲                        │
   │                        │（他星選択は育成中は不可：4.3 参照）
   └──── 別の未完成星を選択（育成未開始 or 育成完了後）
```

### 3.3 キャラクター

| 項目 | 仕様 |
|------|------|
| 見た目 | かわいい人間型、またはマスコット |
| 画像素材 | **別途用意**（本リポジトリ／アセットフォルダに配置） |
| 対応関係 | 星ごとに1体（星ID ↔ キャラクター画像のマッピング） |
| 表示タイミング | 進捗 100% 到達時（祝福演出と合わせて、または演出後に確定表示） |
| 未用意時の扱い | プレースホルダ画像、または簡易シルエットで代替（開発用） |

## 4. ゲームプレイ仕様

### 4.1 星の選択

1. プレイヤーは未完成の星をクリックして選択する
2. 選択中の星は視覚的に分かるよう強調する（例：わずかな拡大、輪郭グロー、選択リング）
3. 完成済みの星をクリックした場合は、キャラクター確認のみとし、育成は開始できない
4. 同時に選択できる星は **1つだけ**

### 4.2 育成の開始

1. 星が選択されている状態で「育成」ボタンを押す
2. 選択中の星が `育成中` になり、進捗が時間経過で増加する
3. 育成開始時点で進捗が 0% の場合は 0% から開始する
4. （将来拡張案）中断・再開がある場合は進捗を保持する。**初版では育成は開始後自動進行し、完了まで継続**とする

### 4.3 育成中の制約（初版）

| 項目 | 仕様 |
|------|------|
| 同時育成数 | **1星のみ** |
| 他星の選択 | 育成中は他の星を選択できない（操作ロック） |
| 育成のキャンセル | 初版では不可 |
| 育成完了後 | 祝福演出の終了後、未完成の星を再び選択可能 |

### 4.4 進捗システム

| 項目 | 仕様 |
|------|------|
| 進捗範囲 | 0% 〜 100% |
| 進行方式 | 時間経過による線形増加（一定速度） |
| 育成所要時間 | **星1つあたり 1分（60秒）**（設定値として外出し推奨） |
| 表示 | プログレスバー＋進捗％＋残り時間 |

#### 4.4.1 表示項目

| 表示 | 内容 | 例 |
|------|------|-----|
| プログレスバー | 0〜100% を視覚的に示すバー | バーが右へ伸びる |
| 進捗％ | 整数または小数1桁のパーセント表示 | `42%` |
| 残り時間 | `分:秒` または `秒` 表示 | `残り 00:18` |

残り時間の計算：

```
残り秒数 = 育成所要時間 × (1 - 現在進捗/100)
```

### 4.5 星の光色変化

進捗に応じて星の発光色が段階的に変化する。

| 進捗閾値 | 色 | 備考 |
|----------|-----|------|
| 0% 以上 〜 25% 未満 | **黄色** | 開始直後（初期色） |
| **25%** 以上 〜 50% 未満 | **青色** | 第1段階 |
| **50%** 以上 〜 75% 未満 | **赤色** | 第2段階 |
| **75%** 以上 〜 100% 未満 | **紫色** | 第3段階 |
| **100%** | キャラクター完成 | 光点からキャラクターへ移行 |

補足：

- 色変化は初期黄＋育成後3段階（青 → 赤 → 紫）で確定
- 色の切り替えは閾値到達時点での段階切替とする（スムーズ補間は行わない）
- 発光の強さ（輝度・グロー半径）は進捗に応じて徐々に強めてもよい（任意演出）

### 4.6 完成・祝福演出

進捗が **100%** に到達したとき：

1. 星の育成を完了状態にする
2. 対応するキャラクター画像を表示する（光点からキャラクターへ遷移）
3. **祝福演出**を再生する  
   - **パーティクル演出で祝福する**（確定）
   - 完成した星／キャラクター周辺から光の粒子が広がる、または降り注ぐイメージ
   - 粒子の色は完成直前の紫や明るい白〜金色系など、祝福感のある色を用いる
   - 画面中央メッセージ「完成！」の表示は任意（パーティクルを主とする）
   - 音は任意（初版スコープ外でも可）
4. 祝福演出の再生中は、次の操作を一時ロックする（推奨）
5. 演出終了後、未完成の星があれば選択可能になる
6. すべての星が完成した場合は、クリア演出／全キャラ一覧表示など（**将来拡張**。初版は「全星完成」メッセージ程度で可）

### 4.7 次の星の選択

1. 1体完成後、プレイヤーはまだ未完成の星をクリックして選択できる
2. 再び「育成」ボタンで次の星の育成を開始できる
3. 完成済みの星は夜空上にキャラクターとして残る

### 4.8 待ち時間のインタラクション（確定）

#### 4.8.1 応援タップ

| 項目 | 仕様 |
|------|------|
| 操作 | 育成中の星をタップ／クリックする |
| 演出 | 小さなパーティクルが散り、星が一瞬大きく脈打つ |
| 効果 | 1回あたり約 0.5 秒育成を短縮。1回の育成につき合計最大 **5秒** まで |
| クールダウン | 連打防止のため約 0.35 秒 |
| ログ | 応援に応じた短いメッセージを成長ログへ追加 |

#### 4.8.2 成長ログ

| 項目 | 仕様 |
|------|------|
| 表示位置 | 下部パネル内（プログレス下） |
| 内容 | 育成開始・色変化マイルストーン・応援・完成などの短文 |
| マイルストーン | 0% / 25% / 50% / 75% / 100% |
| 表示件数 | 直近おおよそ 4 件 |

#### 4.8.3 完成キャラクターのポップアップ

| 項目 | 仕様 |
|------|------|
| 操作 | 完成済みのキャラクターをクリックすると詳細ポップアップを表示する |
| 表示内容 | キャラクター画像、キャラクター名、育成成功メッセージ |
| メッセージ方針 | 「育ててくれてありがとう」「おめでとう」を軸にした文面 |
| 閉じ方 | × ボタン、背景クリック、`Esc` キー |
| 目的 | 育成成功の達成感を強め、各キャラクターへの愛着を高める |

## 5. UI 仕様

### 5.1 画面構成（初版）

```
┌─────────────────────────────────────────────┐
│  タイトル / ゲーム名（任意）                    │
├─────────────────────────────────────────────┤
│                                             │
│              夜空ステージ                     │
│         ★  ★    ★      ★                 │
│      ★        ★    ★                     │
│         ★   ★        ★                   │
│                                             │
├─────────────────────────────────────────────┤
│  [選択中の星: 星3]                            │
│  ████████████░░░░░░░░  42%   残り 00:35     │
│                      [ 育成 ]                │
└─────────────────────────────────────────────┘
```

### 5.2 UI 要素一覧

| 要素 | 説明 | 表示条件 |
|------|------|----------|
| 夜空ステージ | 星／完成キャラを配置 | 常時 |
| 選択情報 | 選択中の星名または番号 | 星選択時 |
| プログレスバー | 選択中（または育成中）の星の進捗 | 星選択時／育成中 |
| 進捗％テキスト | 数値パーセント | 同上 |
| 残り時間テキスト | 残り時間 | 育成中（未開始時は総所要時間または「―」） |
| 育成ボタン | 育成開始 | 未完成の星選択時、かつ非育成中 |
| 祝福オーバーレイ | 完成演出 | 完成時のみ |

### 5.3 育成ボタンの活性条件

| 条件 | ボタン状態 |
|------|------------|
| 星未選択 | 無効 |
| 未完成の星を選択、かつ育成中でない | **有効** |
| 育成中 | 無効（または「育成中…」表示） |
| 完成済みの星を選択 | 無効 |

### 5.4 フィードバック

- 星ホバー時：カーソル変化、わずかなハイライト（デスクトップ）
- 選択時：選択リング／拡大
- 色変化時：短いフラッシュや色遷移アニメ（任意）
- 完成時：パーティクルによる祝福演出（必須）

## 6. データ仕様

### 6.1 星エンティティ（論理モデル）

```js
// 論理モデル（JavaScript オブジェクトとして実装）
{
  id: "star-01",                 // "star-01" ... "star-10"
  x: 0.25,                       // ステージ上の相対座標 (0〜1)
  y: 0.4,
  progress: 0,                   // 0〜100
  status: "idle",                // "idle" | "selected" | "growing" | "completed"
  colorPhase: "initial",         // "initial" | "yellow" | "blue" | "red" | "purple"
  characterImageUrl: "assets/characters/star-01.png"
}
```

### 6.2 色フェーズの判定ルール

```
progress < 25  → initial
progress < 50  → yellow
progress < 75  → blue
progress < 80  → red
progress < 100 → purple
progress >= 100 → completed（キャラクター表示）
```

### 6.3 キャラクターアセット

| 項目 | 仕様 |
|------|------|
| 配置先 | `assets/characters/` |
| 命名（案） | `star-01.png` … `star-10.png`（星IDと対応） |
| 形式 | PNG（透過推奨）／WebP など |
| 不足時 | 開発用プレースホルダを使用 |

### 6.4 設定値（調整用）

| キー | 初期値 | 説明 |
|------|--------|------|
| `STAR_COUNT` | `10` | 星の個数 |
| `GROWTH_DURATION_MS` | `60000` | 星1つあたりの育成時間（1分） |
| `COLOR_THRESHOLDS` | `[25, 50, 75]` | 色変化閾値（%）。初期は黄 |

## 7. 演出・ビジュアル方針

| 項目 | 方針 |
|------|------|
| 世界観 | 静かで優しい夜空。過度な UI ノイズを避ける |
| 星の光 | 点光源＋ソフトなグロー |
| 成長感 | 色変化と輝度上昇で「育っている」ことを伝える |
| 初期色 | **黄色**（背景に埋もれない視認性を優先） |
| 完成 | 光→キャラクターへの変身感と、パーティクル祝福で達成感を出す |
| 祝福演出 | **パーティクル**を主軸としたお祝い演出 |
| モーション | 星のまたたき、選択時の反応、完成時のパーティクルなど、意図的な動きを数点入れる |

## 8. 非機能要件（初版）

| 項目 | 仕様 |
|------|------|
| フレーム更新 | 進捗は requestAnimationFrame または同等のタイマーで滑らかに更新 |
| レスポンシブ | デスクトップを主対象。モバイルでも星タップ・育成操作が可能 |
| 永続化 | 初版ではリロードでリセット（ローカルストレージ保存は将来拡張） |
| アクセシビリティ | ボタンにラベル、進捗はテキストでも分かるようにする |
| パフォーマンス | 星10個＋軽量パーティクル程度で問題なく動作すること |

## 10. 受け入れ条件（初版）

以下を満たせば初版完成とする。

1. 夜空に星が約10個表示され、クリックで1つ選択できる
2. 選択後に育成ボタンで育成を開始できる
3. プログレスバー・進捗％・残り時間が表示され、時間経過で更新される
4. 進捗 25% / 50% / 75% で星の色が青→赤→紫に変化する（初期は黄）
5. 100% でキャラクター画像が表示され、パーティクルによる祝福演出が再生される
6. 完成後、別の未完成星を選択して同様に育成できる
7. キャラクター画像は外部アセット差し替えで対応できる
